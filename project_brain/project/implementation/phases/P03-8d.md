# P03 — 8D Problem Solving (end-to-end)

**Status:** Backend ✅ done · FE 🟡 partial
**Design jsx:** `eightd.jsx`, `eightd-agentic.jsx`, `eightd-templates.jsx`, `eightd-pdf.jsx`
**Spec:** 02 §3, 03 §3, 06 (AI), FEATURES §6 · **Code:** `8D-YYYY-NNNN`
**Value:** structured root-cause discipline for OEM-facing quality escapes (VDA/CQI expectation).

## 1. Feature scope (from jsx)
- **List** (Active / Completed) with D1–D8 mini progress stepper, team lead, status, dates.
- **Detail** — stepped workflow + step navigator:
  - **D1** Team · **D2** Problem (statement, **IS / IS-NOT** table, quantification, customer impact) · **D3** Interim Containment (+ customer notification, effectiveness) · **D4** Root Cause (5 Whys, Fishbone, Fault tree, **AI suggestions w/ confidence + accept/dismiss**, escape point, verification) · **D5** Permanent CA (+ decision matrix scoring, verification plan) · **D6** Implement & Validate (checklist, before/after, customer validation) · **D7** Prevent Recurrence (systemic, training, control-plan/FMEA updates, horizontal deploy, poka-yoke) · **D8** Close & Congratulate (recognition, lessons, final metrics/cost, sign-offs).
- **Agentic AI copilot** (`eightd-agentic.jsx`): per-field AI draft controls, AI card headers, **provenance strip**, **copilot rail**, **Generate Pack** modal — drafts with source/confidence attribution.
- **8D templates** (`eightd-templates.jsx`): list + editor (industry prompts, default roles, SLA per step).
- **8D PDF** (`eightd-pdf.jsx`): branded D1–D8 report with diagrams + signatures.
