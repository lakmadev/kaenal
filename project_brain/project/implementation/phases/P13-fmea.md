# P13 — FMEA Workbench (end-to-end)

**Status:** Backend 🔴 `PROPOSED` · FE 🔴
**Design jsx:** `qms-risk-spc.jsx` (`FMEAWorkbench`, `FMEA_ROWS`, `APBadge`, `ScoreBox`)
**Spec:** FEATURES §12 — **designed here, needs sign-off** · AIAG-VDA harmonized
**Value:** PFMEA/DFMEA is a hard IATF 16949 requirement; live Action-Priority re-scoring drives prevention.

## 1. Feature scope (from jsx)
- **PFMEA / DFMEA** toggle. Per-part FMEA (program selector, **Rev**, N process steps, N failure modes, "last updated").
- Worksheet columns: **# · Process function · Failure mode · Effect · SEV · Cause · OCC · Prevention control · Detection control · DET · AP**. `SEV/OCC/DET` are 1–10; **AP** = AIAG-VDA **Action Priority** (High/Medium/Low, *not* legacy RPN) computed from the SEV×OCC×DET table.
- Row selection → detail; **Export AIAG form** (xlsx); live re-score as actions complete.

## 2. Backend — `PROPOSED`, migration `0023_fmea.sql`
- **`fmeas`**: `tenant_id`, `id`, `code`, `kind` (`pfmea|dfmea`), `part_no`, `program`, `rev` int, `status`, `owner` (composite member FK), `lock_version`. FORCED RLS.
- **`fmea_rows`**: `tenant_id`, `fmea_id`, `seq` int, `process_function`, `failure_mode`, `effect`, `sev` int 1–10, `cause`, `occ` int 1–10, `prevention_control`, `detection_control`, `det` int 1–10, `ap` (`high|medium|low`, generated by rule), `recommended_action`, `action_owner` (member FK), `action_due`, `action_status`, `sev_after/occ_after/det_after` (post-action re-score). Unique `(tenant_id, fmea_id, seq)`.
- **`packages/core/fmea-ap.ts`** (pure, **the crux**): the AIAG-VDA **Action Priority lookup** (SEV, OCC, DET → H/M/L). Fully table-driven and unit-tested against the AIAG-VDA AP table. Never store AP as free input — always derived.
- Contract: `GET /v1/fmeas` (filters kind/part/status), `GET/POST /v1/fmeas(/:id)`, `POST /v1/fmeas/:id/rows` + row update (re-derives AP), `GET /v1/fmeas/:id/export?format=xlsx` (reuse the `exports` job → AIAG form). Mutations `withAudit`; `lockVersion`.
- Enums: `FmeaKind`, `ActionPriority`.

## 3. Frontend (maps to jsx)
- **Route:** `/fmea`.
- **Components:** PFMEA/DFMEA Segmented, program selector, worksheet **table** (min-width scroll, `ScoreBox` 1–10 cells, **`APBadge`** H/M/L color), row detail panel (edit SEV/OCC/DET + controls + recommended action → live AP), Export-AIAG button (async job + download).
- **States:** empty/loading/error; "Rev N · X steps · Y failure modes" summary line.
