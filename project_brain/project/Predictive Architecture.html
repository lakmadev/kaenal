Layer 4 · Stream processing
Rules engine / anomaly processor
Flink / Kafka Streams · stateful windows

Windowing (CEP)

sliding 10-min

Tumbling & sliding windows per asset; pattern & sequence detection.

Baseline store

historical μ / σ

Rolling mean & sigma per metric/asset, refreshed nightly from telemetry.raw.

Anomaly scorer

z-score + ML

Robust z-score for drift; isolation-forest / forecast residual for complex modes.

Rule registry

versioned DSL

Declarative rules (rule.weld.feed_drift.v3) with thresholds & severity maps.

Confidence model

0–1 score

Blends z-score, recurrence & historical NCR matches into one confidence.

Evaluate against baseline · example
metric = wire_feed_speed observed 9.84 m/min baseline μ 9.10 · σ 0.18 z = 4.11 +8.1% drift recurrence: 3rd in 30d
emit → quality.anomalies
Layer 5 · Decision
Anomaly gate
deterministic · auditable
Gate condition
if (z_score >= 3.5
  && confidence >= 0.80
  && !suppressed)
  → draft NCR
WITHIN BASELINE

store to time-series · update baseline · no action

WATCH

2 <= z < 3.5 · raise a soft signal on the Predictive-Risk board

ANOMALY

passes gate · correlate & dedupe · write Draft NCR

Correlation & dedupe

Group bursts on the same asset+metric into one NCR · attach all source events · suppress if an open NCR already covers this scope.
