# Sprints

One file per sprint: `SPRINT-<NN>-<slug>.md`, written by the `product-owner` agent (stories, use cases, acceptance criteria, web/mobile/shared breakdown, DoD, sign-off). See `/SCRUM.md` for the process. Never delete a sprint file; it is the record of what was agreed.

A sprint whose scope is split by the PO into separately gated increments of the **same release** uses a letter
suffix for the split-off file (e.g. `SPRINT-07C-staff-console.md` = Sprint 07, Increment C). Suffixed files keep the
parent sprint's number; later sprints are not renumbered.
